# 🚀 Go-Ossetia

**Go-Ossetia** — это современная веб-платформа для организации локальных встреч, поиска единомышленников во Владикавказе. Проект призван разрушить барьер первого сообщения, помогая людям выбираться из онлайна и объединяться вокруг общих интересов: от активного спорта и настольных игр до культурных событий и уютных пикников.

---

## 🎨 Стилистика и Дизайн

Интерфейс платформы выполнен современном минималистичном стиле, чтобы пользователь мог мамксимально просто и удобно доходить до целевого действия.

---

## 🛠 Стек технологий

* **💻 Frontend:** React (компонентный подход)
* **👀 Styling:** Tailwind CSS
* **🎨 Design & Assets:** Figma, Adobe Photoshop
